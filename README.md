# Vivero · página para PC

Repo **público** con la versión para PC de la app del vivero (GitHub Pages) y el robot del clima.

- No editar a mano: la página la publica el repo privado `vivero--movil` (workflow *Pagina PC*) cada vez que cambia la app.
- El robot del clima (`.github/workflows/clima.yml`) corre cada 15 min y deja `clima.json` en la rama `datos`.
- Acá no hay claves ni código del firmware.
